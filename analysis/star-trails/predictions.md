# Predictions for the star-trails test matrix

Generated by `tools/refcalc.py`. Do not edit by hand; change the script and regenerate.

- **A** = spherical astronomy (Meeus algorithms; Sun good to about 0.01 deg, stars precessed from J2000,
  no proper motion, no refraction on altitudes).
- **C** = the app's own map taken literally: body at height h over its sub-point on the AE plane,
  straight-line sight. h is a free parameter, so C is shown for 3000, 5000 and 6000 km.
- Azimuths are degrees from north through east. These are predictions, not measurements of the app.

## 5. Midnight Sun, and why a range cut-off does not rescue C (test ST8)

Under straight-line C the Sun never sets anywhere (section 2). The usual repair is a maximum range
beyond which the Sun is not seen. This compares map distances from the sub-solar point at one instant.

- **McMurdo**, 2026-12-20 12:53 UTC (the Sun's lowest point that day): globe altitude +11.3 deg, so it is
  up all 24 hours. Map distance from the sub-solar point (-23.4, -13.9): 31,277 km.
  At the same instant **Tokyo** has the Sun at -64.1 deg (night) and is 18,223 km from the
  sub-solar point on the map. The sunlit place is 1.7x farther from the map Sun than
  the dark one, so no single visibility range reproduces both.
- **Tromso**, 2027-06-20 22:46 UTC (the Sun's lowest point that day): globe altitude +3.1 deg, so it is
  up all 24 hours. Map distance from the sub-solar point (23.4, -161.1): 9,664 km.
